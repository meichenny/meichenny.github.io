# meichenny.github.io

Mei Chen's blog, built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme, deployed to GitHub Pages by `.github/workflows/pages.yml`.

- Hugo 0.168.0 (pinned in the workflow, checksum verified); PaperMod is a submodule pinned to a commit.
- New post: `content/posts/<slug>.md` with `title`, `date`, `tags` and `description` front matter. Math: `\( \)` inline, `$$ $$` block, rendered at build time.
- Local preview: `hugo server`.
